# Awesome ServiceNow [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of high-quality resources for learning, building, operating, architecting, and extending the ServiceNow AI Platform.

ServiceNow is a large ecosystem. This list favors authoritative, active, useful resources for administrators, developers, architects, platform owners, DevOps teams, AI builders, and community contributors.

> Note: The initial version of this list was curated with help from an AI agent, so some links, descriptions, or categorization choices may contain errors. Please open an issue or pull request if you spot something inaccurate, outdated, duplicated, or missing.
